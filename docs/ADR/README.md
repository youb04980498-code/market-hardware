# Architecture Decision Records

Consigner les décisions importantes avec contexte, choix, alternatives et conséquences. La référence courante est le [cahier des charges V3](../MARKET_HARDWARE_CAHIER_DES_CHARGES_V3.md). L'architecture V1 est historique ; la V3 prévaut en cas de divergence.

Convention : `NNNN-titre-court.md`, avec les sections statut, contexte, décision et conséquences. Prévoir au moins une décision par volet : stockage SQL/NoSQL, lakehouse, microservices/API et streaming.
